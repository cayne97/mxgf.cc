## 一、平台是什么

**RVC 模型工坊**（mxgf.cc）是一个面向 RVC / SVC 生态的音色模型下载与定制平台，覆盖：

| 板块 | 内容 |
|---|---|
| RVC 翻唱变声系统 | v10.9 桌面版，一键翻唱 / 实时变声 / 歌曲改词，Windows 一键启动 |
| SVC 模型（翻唱 / 音色替换） | 动漫角色、明星音色、原创音色、少年音 / 正太音等 |
| RVC 全新自研底模 | Mygf 系列预训练底模（F040K / F048K 等），少样本训练效果更稳 |
| 模型定制 | 提供声音克隆定制，从素材提交到成品交付全流程 |
| 会员 | 终身炼丹师 / 高级炼丹师 / 终身永久会员，权益见官网 |

## 三、下载与使用

1. 登录 mxgf.cc 后在模型页获取下载地址（网盘直链 / 提取码以页面显示为准）。
2. 模型文件为 `.pth` 格式，配套 RVC 主程序使用：
   - 下载并解压 RVC 主程序；
   - 将 `.pth` 放进 `weights` 目录；
   - 启动 `infer-web.py`；
   - 选模型 → 上传音频 → 推理。
3. 一体化整合包与客户端下载：<https://mxgf.cc/>（软件下载 / 教程分类）。

> 提示：仓库内不放网盘链接，避免链接失效后产生误导与二次传播，**请以官网模型页为准**。

RVC / SVC 生态里有第三方站点**冒用「RVC 模型工坊」「妙音 / MiaoYin」「Mygf 底模」等名称**，并以「免费 RVC 模型下载」「官方模型站」为名收费售卖模型或模型定制服务。常见特征：

- 域名不是 `mxgf.cc`（例如 `klrvc.com` 一类近似域名，或 `*.value.4000388378.com` 一类第三方建站二级域名）；
- 页面标题写「妙音 / RVC 模型工坊 / MiaoYin」，却不是官方备案主体；
- 要求把「官方模型下载」指向该站，再从中收取模型费、定制费、会员费。

**判定标准很简单：**

1. 官方网站只有 <https://mxgf.cc/>（备案号 闽ICP备2022000000号）；
2. 客服只有 **QQ 924620459** / 微信 **mxgfkf**；
